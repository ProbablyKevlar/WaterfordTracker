**System Role:**
Act as an expert full-stack Python developer specializing in Streamlit, SQLite, and Docker. Your task is to build a mobile-responsive Track & Field Performance Tracking dashboard for a high school team (Waterford Track & Field).

**Tech Stack:**
- Frontend & Backend: Streamlit (Python)
- Visualizations: Plotly (mobile-responsive charts)
- Database: SQLite (via SQLAlchemy or sqlite3)
- Authentication: `streamlit-authenticator` (hashed passwords for Admin/Coach accounts, open access for Public Read-Only)
- Deployment: Docker (must include a Dockerfile optimized for Synology NAS Container Manager with persistent external volume mounting)

---

**Database Schema Requirements:**
1. **Athletes:** 
   - `id` (INTEGER PRIMARY KEY)
   - `first_name` (TEXT), `last_name` (TEXT)
   - `gender` (TEXT: 'M' / 'F')
   - `age` (INTEGER)
   - `grade_level` (INTEGER: 7-12)
   - `active_status` (BOOLEAN)

2. **Venues (Tracks):** 
   - `id` (INTEGER PRIMARY KEY)
   - `name` (TEXT)
   - `season` (TEXT: 'Indoor', 'Outdoor', 'Both')
   - `lap_distance_meters` (REAL)
   - *Required Seed Data:* "Outdoor Track" (400m), "HVCC Indoor" (200m), and "Union Fieldhouse" (160m).

3. **Events:** 
   - `id` (INTEGER PRIMARY KEY)
   - `season` (TEXT: 'Indoor', 'Outdoor')
   - `event_name` (TEXT)
   - `event_type` (TEXT: 'Track', 'Field', 'Relay')
   - `distance_meters` (REAL, nullable for field events)
   - `sort_order` (TEXT: 'ASC' for Track/Relay where lower time is faster; 'DESC' for Field where higher/longer mark is better)
   - *Indoor Events:*
     - Track: 55m, 55m Hurdles, 300m, 600m, 1000m, 1500m, 1600m, 3000m, 3200m
     - Relays: 4x200m, 4x400m, 4x800m, 1600m Sprint Medley (SMR), Distance Medley (DMR)
     - Field: Shot Put, High Jump, Pole Vault, Long Jump, Triple Jump, Weight Throw
   - *Outdoor Events:*
     - Track: 100m, 100m Hurdles (Girls), 110m Hurdles (Boys), 200m, 400m, 400m Hurdles, 800m, 1500m, 1600m, 3000m, 3200m, 2000m Steeplechase, 3000m Steeplechase
     - Relays: 4x100m, 4x400m, 4x800m, 1600m Sprint Medley (SMR), Distance Medley (DMR)
     - Field: Shot Put, Discus, High Jump, Pole Vault, Long Jump, Triple Jump, Javelin

4. **Meets:**
   - `id` (INTEGER PRIMARY KEY)
   - `name` (TEXT, e.g., "Wasaren League Championships", "Dual vs Stillwater", "Section 2 State Qualifier", "Intra-Squad Time Trial")
   - `date` (DATE)
   - `venue_id` (INTEGER, REFERENCES Venues)
   - `season` (TEXT: 'Indoor', 'Outdoor')
   - `meet_type` (TEXT: 'Dual', 'Invitational', 'Championship', 'State Qualifier', 'Practice / Time Trial')

5. **Results (Individual Events):** 
   - `id` (INTEGER PRIMARY KEY)
   - `athlete_id` (INTEGER, REFERENCES Athletes)
   - `event_id` (INTEGER, REFERENCES Events)
   - `meet_id` (INTEGER, REFERENCES Meets)
   - `result_value` (REAL: Stored strictly as numeric base units—seconds for track, meters for field)
   - `timing_method` (TEXT: 'FAT' [Fully Automatic Timing] or 'Hand' [Hand Timed])
   - `is_official` (BOOLEAN: True for official competition meets, False for practice/time trials)
   - `notes` (TEXT, nullable)

6. **Relay_Results:** 
   - `id` (INTEGER PRIMARY KEY)
   - `event_id` (INTEGER, REFERENCES Events)
   - `meet_id` (INTEGER, REFERENCES Meets)
   - `total_time_seconds` (REAL: Numeric float seconds)
   - `timing_method` (TEXT: 'FAT' or 'Hand')
   - `is_official` (BOOLEAN)
   - `notes` (TEXT, nullable)

7. **Relay_Legs (Normalized Relay Splits):**
   - `id` (INTEGER PRIMARY KEY)
   - `relay_result_id` (INTEGER, REFERENCES Relay_Results ON DELETE CASCADE)
   - `leg_number` (INTEGER: 1, 2, 3, 4)
   - `athlete_id` (INTEGER, REFERENCES Athletes, nullable)
   - `split_seconds` (REAL, nullable: Numeric float seconds)
   - `notes` (TEXT, nullable)

8. **Standards (Championship & Record Benchmarks):**
   - `id` (INTEGER PRIMARY KEY)
   - `event_id` (INTEGER, REFERENCES Events)
   - `gender` (TEXT: 'M' / 'F')
   - `standard_name` (TEXT, e.g., "School Record", "Section 2 Standard", "State Qualifier Standard")
   - `standard_value` (REAL: seconds for track, meters for field)

**Core Application Features:**

1. **Role-Based Access Control:** 
   - *Coach (Admin):* Requires login with hashed credentials. Can access CRUD forms to manage Athletes, Venues, Meets, Individual Results, Relay Results, and Standards.
   - *Public (Read-Only):* No login required. Can view all dashboards, leaderboards, athlete profiles, and the pace calculator.

2. **Data Entry Forms (Admin Only):**
   - *Single Result Entry:*
     - Dynamic dropdowns: Selecting "Indoor" or "Outdoor" filters available events, venues, and meets.
     - Field Events Toggle: Coach can enter field marks in Metric (meters) or Imperial (feet & inches, e.g., `38' 6.5"`). The app automatically parses imperial inputs to meters for database storage.
     - Track Time Formatter: Supports flexible input (e.g., `11.45`, `2:04.12`, `10:15.5`) automatically parsed to float seconds.
     - Timing Method & Official Status: Select FAT vs Hand Timing, and toggle Official Meet vs Practice / Time Trial.
   - *Bulk / Quick Entry Mode (`st.data_editor`):*
     - Allows a coach to pick a Meet and Event, then quickly log or edit times/distances for an entire heat or flight of rostered athletes in a single interactive table.
   - *Relay Entry Form:*
     - Enter overall team time with optional assignment of rostered athletes and individual split times for legs 1 through 4.
   - *Historical Backdating & Editing:*
     - Coaches can easily backdate previous seasons' results and edit/delete existing records.

3. **Pace Calculator & Clipboard Lap Expectations:**
   - Coach or athlete selects an event/distance and a target finish time (e.g., 1600m in 4:48.00).
   - Selects a venue (reading `lap_distance_meters`—e.g., Union 160m, HVCC 200m, Outdoor 400m).
   - Calculates the exact required pace per lap and per 100m.
   - Generates a clipboard-ready cumulative split breakdown table (Lap 1, Lap 2, ... Final) with target stopwatch times for coaches on the track.

4. **Athlete Profile & Progression Dashboard:**
   - Search/select an athlete to view their complete profile (Grade, Gender, Active Status).
   - **PR & SB Detection:** Automated badges for All-Time Personal Records (PR) and Season Bests (SB), displaying delta improvement (e.g., "-1.8s improvement").
   - **Interactive Performance Trend Charts:** Plotly line charts showing progression over time per event.
   - **Relay Split History:** Displays an athlete's relay splits alongside their open individual times.
   - **Multi-Season Year-over-Year Progression:** Comparison table/chart showing progression from freshman through senior seasons.

5. **Team Leaderboard & Standards Tracker:**
   - **Honor Roll:** Team Top 5 Current Season and Top 10 All-Time leaderboards per event.
   - **Standards Tracker:** Visual progress bars displaying each athlete's proximity to Section 2, State Qualifier, and School Record benchmarks.
   - **Relay Lineup Builder:** Tool allowing coaches to select 4 athletes to project team relay times based on best individual splits and open marks.

6. **Mobile-Responsive Design:**
   - Clean, touch-friendly UI using Streamlit containers and CSS metrics that stack naturally on mobile phone browsers.
   - Plotly charts configured with responsive touch interaction.
